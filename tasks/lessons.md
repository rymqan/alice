# Lessons

Corrections from the user and rules derived from them. Newest first.

## 2026-11-08 — "continue on another device" meant another developer
- Pattern: I assumed "another device" = same person, same accounts, and built the hand-off around Remote Control and copying `~/.claude` between the owner's Macs.
- Rule: when asked to "share/continue a session", first state who the recipient is (same person vs another account) and where state must live. Prefer file-based hand-off (repo + transcript) that works for anyone; mention account-bound features (Remote Control, cloud sessions) only as optional extras.
